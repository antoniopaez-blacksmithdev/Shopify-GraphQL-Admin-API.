# DraftOrderList

## Español 🇪🇸

Los borradores de pedido permiten preparar ventas antes de convertirlas en pedidos completos. `DraftOrderList` ayuda a revisar el trabajo comercial pendiente sin ejecutar mutaciones ni alterar el estado de ningún borrador.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: DraftOrder** — representa un pedido preparado pero todavía no convertido.
- **Field: status** — estado actual del borrador.
- **Field: totalPriceSet** — total expresado en la moneda de la tienda.
- **Scopes:** `read_draft_orders`.
- **URL del objeto elegido:** [DraftOrder](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/DraftOrder)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

Draft orders let merchants prepare sales before converting them into completed orders. `DraftOrderList` helps review pending commercial work without running mutations or changing any draft state.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: DraftOrder** — represents an order prepared but not yet converted.
- **Field: status** — current draft status.
- **Field: totalPriceSet** — total expressed in the shop currency.
- **Scopes:** `read_draft_orders`.
- **URL of the selected object:** [DraftOrder](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/DraftOrder)

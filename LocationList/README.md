# LocationList

## Español 🇪🇸

Las ubicaciones representan tiendas, almacenes y otros puntos desde los que se gestiona inventario o se prepara actividad operativa. `LocationList` permite obtener una vista compacta de esos puntos con paginación.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Location** — representa un punto operativo de la tienda.
- **Field: name** — nombre identificable de la ubicación.
- **Field: address** — dirección postal asociada a la ubicación.
- **Scopes:** `read_locations`.
- **URL del objeto elegido:** [Location](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Location)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

Locations represent shops, warehouses, and other points from which inventory or operational activity is managed. `LocationList` provides a compact, paginated view of those points.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: Location** — represents an operational point for the shop.
- **Field: name** — identifying name of the location.
- **Field: address** — postal address associated with the location.
- **Scopes:** `read_locations`.
- **URL of the selected object:** [Location](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Location)

# ProductByIdentifier

## Español 🇪🇸

Buscar por handle evita depender de un GID cuando una integración ya conoce el identificador legible de la URL. `ProductByIdentifier` usa `productByIdentifier` con el campo `handle` y devuelve null si no existe una coincidencia.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Product** — producto localizado mediante un identificador flexible.
- **Field: handle** — valor utilizado para encontrar el producto.
- **Field: title** — título principal del producto encontrado.
- **Scopes:** `read_products`.
- **URL del objeto elegido:** [ProductByIdentifier](https://shopify.dev/docs/api/admin-graphql/2026-04/queries/productByIdentifier)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

Searching by handle avoids depending on a GID when an integration already knows the readable URL identifier. `ProductByIdentifier` uses `productByIdentifier` with `handle` and returns null when no match exists.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: Product** — product located through a flexible identifier.
- **Field: handle** — value used to find the product.
- **Field: title** — main title of the product found.
- **Scopes:** `read_products`.
- **URL of the selected object:** [ProductByIdentifier](https://shopify.dev/docs/api/admin-graphql/2026-04/queries/productByIdentifier)

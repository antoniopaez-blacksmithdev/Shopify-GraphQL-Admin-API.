# CustomerList

## Español 🇪🇸

Una lista de clientes es el punto de partida para segmentar audiencias, revisar cuentas y construir sincronizaciones con CRM. `CustomerList` usa la conexión `customers` y selecciona únicamente campos de lectura.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Customer** — representa una persona que interactúa con la tienda.
- **Field: defaultEmailAddress** — dirección de correo principal del cliente.
- **Field: numberOfOrders** — cantidad de pedidos asociados al cliente.
- **Scopes:** `read_customers`.
- **URL del objeto elegido:** [Customer](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Customer)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

A customer list is the starting point for audience segmentation, account review, and CRM synchronisation. `CustomerList` uses the `customers` connection and selects read-only fields only.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: Customer** — represents a person who interacts with the shop.
- **Field: defaultEmailAddress** — customer's primary email address.
- **Field: numberOfOrders** — number of orders associated with the customer.
- **Scopes:** `read_customers`.
- **URL of the selected object:** [Customer](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Customer)

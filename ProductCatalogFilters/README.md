# ProductCatalogFilters

## Español 🇪🇸

Cuando una tienda necesita localizar productos por título, proveedor, colección o cualquier otro criterio compatible con la sintaxis de búsqueda de Shopify, una consulta filtrada evita descargar el catálogo completo. Con **ProductCatalogFilters** puedes construir listados administrativos y procesos de revisión más eficientes.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Product** — representa un producto del catálogo de la tienda.
- **Field: id** — identificador global del producto.
- **Field: status** — estado actual del producto en el catálogo.
- **Scopes:** `read_products`.
- **URL del objeto elegido:** [Product](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Product)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

When a shop needs to locate products by title, vendor, collection, or another criterion supported by Shopify search syntax, a filtered query avoids downloading the entire catalog. With **ProductCatalogFilters**, you can build more efficient administrative lists and review processes.

- **Connection: QueryRoot** — the entry point for the GraphQL query.
- **Object: Product** — represents a product in the shop’s catalog.
- **Field: id** — the product’s global identifier.
- **Field: status** — the product’s current catalog status.
- **Scopes:** `read_products`.
- **URL of the selected object:** [Product](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Product)

# BlogArticleList

## Español 🇪🇸

La estructura de blogs y artículos permite organizar el contenido editorial por temas. `BlogArticleList` recorre dos conexiones paginadas para construir una vista compacta del contenido publicado o planificado.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Blog** — contenedor editorial de artículos.
- **Connection: Article** — artículos pertenecientes a cada blog.
- **Field: handle** — identificador legible del blog o artículo.
- **Scopes:** `read_content`.
- **URL del objeto elegido:** [Blog](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Blog)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

Blogs and articles organise editorial content by topic. `BlogArticleList` traverses two paginated connections to build a compact view of published or planned content.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: Blog** — editorial container for articles.
- **Connection: Article** — articles belonging to each blog.
- **Field: handle** — human-readable identifier for the blog or article.
- **Scopes:** `read_content`.
- **URL of the selected object:** [Blog](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Blog)

# ShopConfiguration

## Español 🇪🇸

La configuración básica de la tienda sirve como contexto para paneles administrativos, integraciones y procesos de sincronización. Con la query `ShopConfiguration` puedes leer estos datos sin recorrer colecciones ni recursos comerciales.

- **Connection: QueryRoot** — punto de entrada de la consulta GraphQL.
- **Object: Shop** — representa la tienda cuyo contexto se consulta.
- **Field: name** — nombre visible de la tienda.
- **Field: myshopifyDomain** — dominio permanente asignado por Shopify.
- **Scopes:** no requiere un scope de recurso específico; necesita un token Admin API válido.
- **URL del objeto elegido:** [Shop](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Shop)

## English 🏴󠁧󠁢󠁥󠁮󠁧󠁿

Basic shop configuration provides context for administrative dashboards, integrations, and synchronisation processes. With the `ShopConfiguration` query, you can read these values without traversing collections or commercial resources.

- **Connection: QueryRoot** — entry point for the GraphQL query.
- **Object: Shop** — represents the shop whose context is queried.
- **Field: name** — shop name displayed by Shopify.
- **Field: myshopifyDomain** — permanent domain assigned by Shopify.
- **Scopes:** no resource-specific scope is required; a valid Admin API token is needed.
- **URL of the selected object:** [Shop](https://shopify.dev/docs/api/admin-graphql/2026-04/objects/Shop)
